# 工程图绘制工具页面设计方案

**日期**: 2026-05-10
**版本**: 1.0

---

## 1. 项目概述

为 ATEMall 官网开发一个交互式工程图绘制工具页面，让用户通过 Mermaid.js 代码实时绘制各类工程图。

## 2. 技术选型

| 项目 | 选择 | 理由 |
|------|------|------|
| 技术栈 | 单页 HTML + JavaScript | 轻量、快速部署 |
| 绘图库 | Mermaid.js | 代码驱动，适合工程师，支持多种图类型 |
| CDN | 最新稳定版 | 无需本地安装 |

## 3. 设计风格

- **背景**: 深色 (#1a1a2e 或类似)
- **品牌色点缀**: ATEMall 红 (#e63946) + 银白 (#c0c0c0)
- **字体**: 等宽字体用于代码区 (JetBrains Mono / Source Code Pro)
- **整体**: 工业科技风，契合工控测试领域

## 4. 页面布局

```
┌─────────────────────────────────────────────────────────┐
│  ATEMall 工程图工具                    [清空][复制][导出] │
├─────────────────────────────────────────────────────────┤
│  [流程图] [脑图] [拓扑图] [状态图] [时序图]  ← 图类型切换   │
├───────────────────────────┬─────────────────────────────┤
│                           │                             │
│     代码编辑区             │       实时预览区              │
│     (textarea)            │       (svg rendered)         │
│                           │                             │
│                           │                             │
└───────────────────────────┴─────────────────────────────┘
```

## 5. 功能需求

### 5.1 图类型切换
- 支持 5 种图类型切换
- 切换时自动加载对应模板代码
- 图类型: 流程图、脑图、拓扑图、状态图、时序图

### 5.2 代码编辑
- 左侧文本编辑器
- 语法高亮（可选）
- 实时解析（防抖处理）

### 5.3 实时预览
- 右侧 SVG 渲染区
- 跟随代码变化自动更新
- 错误提示（代码语法错误时显示）

### 5.4 操作按钮
- **清空**: 重置为空白模板
- **复制代码**: 复制当前代码到剪贴板
- **导出图片**: 将预览区 SVG 导出为 PNG 图片

## 6. Mermaid 图类型支持

| 图类型 | Mermaid 语法 | 适用场景 |
|--------|--------------|----------|
| 流程图 | flowchart | 机械框架图、电气功能框图 |
| 脑图 | mindmap | 方案构思、知识整理 |
| 拓扑图 | flowchart + subgraph | 系统架构、网络拓扑 |
| 状态图 | stateDiagram | 状态机、BMS 状态流 |
| 时序图 | sequenceDiagram | 协议交互、时序逻辑 |

```css
  --accent-silver: #c0c0c0;   /* 银白色 */
  --text-primary: #ffffff;
  --text-secondary: #a0a0a0;
  --border: #2a2a4a;
}
```
